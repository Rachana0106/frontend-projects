## 🚀 Running a Project Locally

Choose any project from this collection and clone its repository:

```bash
git clone PROJECT-REPOSITORY-URL
```

Open the project folder:

```bash
cd PROJECT-FOLDER
```

For HTML, CSS and JavaScript projects, open `index.html` directly or use the VS Code **Live Server** extension.

For React projects:

```bash
npm install
npm run dev
```
